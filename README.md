# 📚 Library Management System

A full-stack Library Management System built with:

- React + TypeScript
- Flask
- PostgreSQL
- SQLAlchemy
- JWT Authentication

## Features

- User Authentication
- Role-based Access
- Book Management
- Borrow & Return Books
- Dashboard

## Tech Stack

Frontend
- React
- TypeScript
- React Query
- Tailwind CSS

Backend
- Flask
- Flask SQLAlchemy
- Flask JWT Extended
- PostgreSQL

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
```

### Frontend

```bash
cd frontend
npm install
```
